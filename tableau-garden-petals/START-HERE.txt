GARDEN PETALS: a Tableau viz extension

0. Put Tableau's Extensions API library in lib/ (see lib/README.md). It is Tableau's, so it is not included.
1. Double-click Start-Petals.bat. A window opens and says the server is running. Leave it open.
2. In Tableau Desktop, build a sheet. Drop three fields on the Marks card once Garden Petals is loaded:
     Flower = a dimension (Country)
     Petal  = a dimension (Metric)
     Length = a measure (Value)
     Score  = optional measure (one number per flower)
   Extra fields go on Detail, matched by name: Region/Group, OECD Value/Reference, Rank,
   Hex/Color, Latitude, Longitude, Caution.
3. Marks card > mark type dropdown > Viz Extensions > Add Extension > Access Local Viz Extensions,
   then pick garden-petals.trex from this folder. Click Allow.
4. Click the gear in the top right of the viz for every setting.

Needs Tableau 2024.2 or newer. Viz extensions show blank in PDF and PowerPoint exports.
To host it on the web instead: python tools/package.py --base https://your-host/petals (https only).
